## 📋 Detailed Specifications

### Profile Photo
- **Filename**: `profile-photo.jpg`
- **Size**: 800x800px (square aspect ratio)
- **Format**: JPG or PNG
- **Content**: Professional headshot with neutral background
- **Usage**: Displays in the About section

### CV Document
- **Filename**: `cv.pdf`
- **Format**: PDF
- **Max Size**: 5MB recommended
- **Usage**: Downloaded when users click "Download CV" button

### Open Graph Image
- **Filename**: `og-image.jpg`
- **Size**: 1200x630px (standard for Facebook/LinkedIn)
- **Format**: JPG
- **Content**: Your name + professional tagline with attractive design
- **Usage**: Shows when website is shared on social media

### Favicon
- **Filename**: `favicon.svg`
- **Format**: SVG or ICO
- **Size**: 32x32px minimum
- **Design**: Your initials "CO" or a simple logo
- **Usage**: Browser tab icon

### Organization Logos
- **Format**: PNG with transparent background (preferred)
- **Size**: 200-400px width (height will auto-scale)
- **Quality**: High resolution, official logos
- **Source**: Download from official organization websites

**Where to find logos**:
- Official websites → "Media" or "Press" section
- Search: "[Organization name] logo official"
- Branding guidelines often available online

---

## 🚀 How to Add Images

1. Navigate to your project folder:
   ```
   cd /Users/macintoshhd/Desktop/personal-website
   ```

2. Place all images in the `public/` folder with exact filenames above

3. The website will automatically display them (no code changes needed!)

4. Refresh your browser to see the images appear

---

## 💡 Tips

- **Use high-quality images** - they represent your professional brand
- **Optimize file sizes** - compress images before uploading (use tools like TinyPNG)
- **Keep originals** - save backup copies of all images
- **Test on mobile** - ensure images look good on small screens

---

## ⚠️ Fallback Behavior

If an image is missing:
- **Profile photo**: Shows placeholder with upload instructions
- **Organization logos**: Displays organization name as text
- **Favicon**: Browser shows default icon
- **CV**: Link still works but points to placeholder PDF

The website is fully functional even without images, but adding them will make it complete and professional!
